leaflet-drift-marker

A Leaflet plugin for animated markers that move smoothly to a new position instead of jumping. Click the map to send the marker there, or let it drive the route.

GitHub npm 
npm install leaflet-drift-marker leaflet
import DriftMarker from "leaflet-drift-marker";

const marker = new DriftMarker([38.7071, -9.1355]).addTo(map);
marker.slideTo([38.7139, -9.1394], { duration: 1000, keepAtCenter: true });
